Every diagram is a single self-contained HTML file — dark/light toggle, pan and zoom, search, focus and relationship tracing, and truthful export. Nothing loads from the network, so the whole set works offline and on a locked-down conference laptop.

Each course is a folder, and versions live inside it — this one is containers-101/v1/ — so every course versions on its own schedule and a link you share today keeps showing what it showed today. A version folder holds an index.html entry point, a README.md agenda, rendered diagrams, the specs/ they were generated from, and notes/ holding the talk track. Every path inside is relative, so a version can be copied to create the next one without a single link rewrite.
